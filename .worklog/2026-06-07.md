## 발생 이슈

### 이슈 1: next@15.0.4 보안 취약점 알림 (CVE-2025-66478)
- 원인: `package.json`의 next 버전을 `15.0.4`로 고정해 설치했더니 deprecated 알림.
- 해결: `npm install next@latest eslint-config-next@latest`로 16.2.7로 업그레이드.

### 이슈 2: globals.css에서 `@import url(...)` 파싱 실패 (HTTP 500)
- 원인: Tailwind v4의 `@import "tailwindcss"`가 인라인 확장되면서 1,221줄로 부풀어 오르고, 그 뒤에 적었던 Pretendard `@import url(...)`이 다른 CSS 규칙 뒤로 밀려 CSS 스펙 위반 (`@import` must precede all other rules).
- 해결: Pretendard CDN 로드를 `<link rel="stylesheet">`로 옮겨 `layout.tsx`의 `<head>`에 삽입. `@import` 의존을 제거.

### 이슈 3: `.ai` 로고/캐릭터 파일을 웹에서 직접 사용 불가
- 원인: `images/logo/DIMO_LOGO_자사몰용.ai`, `images/characters/디모프렌즈.ai`는 Adobe Illustrator 포맷.
- 해결: `Logo.tsx`를 텍스트 기반 임시 컴포넌트로 만들었음. 추후 사용자가 SVG/PNG로 추출 후 교체 필요.

## 사용자 확인 필요 사항 (다음 세션)

1. **로고/캐릭터 PNG·SVG 추출** — `.ai` 파일들을 웹용 자산으로 변환해야 `<Logo>` 컴포넌트와 히어로 캐릭터를 실 이미지로 교체할 수 있음.
2. **실제 사업자 정보** — `Footer.tsx`의 사업자등록번호/주소/대표이사 등은 placeholder.
3. **다음 작업 우선순위** — 회원가입/로그인 → 상품 목록/상세 → 장바구니/결제 → 마이페이지 순서로 진행 권장.
4. **백엔드 API 합의 시점** — 1~2개 페이지 더 만들고 나면 OpenAPI 스펙 확정이 필요해짐. dimo_back과 합의 일정 잡기.
