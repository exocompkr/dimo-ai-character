### 3. /ai-character 페이지 생성 (`src/app/ai-character/page.tsx`)

- 우측: 6개 스타일 Grid (이미지 + 스타일명)
- 스타일 선택 시 체크마크 표시
- 생성하기 버튼 + 로딩 상태

### 4. API 라우트 생성 (`src/app/api/ai-character/generate/route.ts`)
- POST /api/ai-character/generate
- GPT-4o Vision으로 아이 특징 분석
- DALL-E 3로 캐릭터 생성 (초록 배경)
- sharp로 크로마키 배경 제거 (HSL 기반)
- 투명 PNG base64 반환

### 5. 패키지 설치
- `openai`: OpenAI API SDK
- `sharp`: 이미지 처리 (크로마키)
- `@types/sharp`: TypeScript 타입
